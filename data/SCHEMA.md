# 图谱数据接口说明（SCHEMA）

## 目录结构

```
.
├── index.html          # 主图页：学科开关、合并大网、搜索、图例、过滤器
├── node.html           # 节点详情页（新窗口打开，?id=D25），含笔记功能栏
├── lib/                # 本地化依赖（cytoscape / dagre / katex）
├── css/style.css       # 样式
├── js/app.js           # 主应用逻辑
├── js/notes-store.js   # 笔记存储（IndexedDB，降级 localStorage）
└── data/
    ├── manifest.js     # 学科注册表
    ├── topology.js     # 拓扑学数据
    ├── analysis.js     # 数学分析（空模板）
    └── algebra.js      # 高等代数（空模板）
```

## 如何新增一个学科

1. 复制 `data/algebra.js` 为 `data/<id>.js`，改名并填入数据；
2. 在 `data/manifest.js` 的 `KG_SUBJECTS` 数组里加一项：
   ```js
   { id: "realanalysis", label: "实分析", color: "#9141ac", file: "data/realanalysis.js" }
   ```
3. 在 `index.html` 和 `node.html` 的 `<script>` 区域，紧跟其他数据文件之后加：
   ```html
   <script src="data/realanalysis.js"></script>
   ```
4. 每个数据文件末尾调用 `window.registerSubject(window.KG_DATA);`（必须保留）。

## 数据文件格式

```js
window.KG_DATA = {
  subject: { id: "topology", label: "拓扑学", color: "#1a5fb4" },

  nodes: [
    {
      id: "P1",                    // 全局唯一（建议学科前缀避免跨学科冲突，如 T_P1 / A_P1）
      kind: "proposition",         // proposition(命题/定理) | definition(定义) | example(特例)
      label: "P1 邻域刻画",         // 图内短名
      title: "P1 · Proposition 2.8（…）",  // 详情页标题
      statement: "设 $X$ 为…",      // 陈述，支持 $...$ / $$...$$（KaTeX）
      proof: "证明位置：习题 2.9",  // 证明位置说明
      ref: "Proposition 2.8",      // 原书编号
      page: 24,                    // 印刷页码（可选）
      pdfPage: 43,                 // PDF 页码（可选）
      pdfUrl: "your-book.pdf#page=43",  // 点击跳转（可选）
      note: "定义于习题"            // 附加说明（可选）
    }
  ],

  edges: [
    // type: equiv(等价，蓝双箭头) | impl(推论，绿单箭头) | aux(证明依赖，灰点线)
    { id: "E1", source: "D25", target: "P2", type: "equiv", label: "等价" }
  ],

  joints: [
    // 联合蕴含：sources 数组 + target（渲染为红色虚线 AND 门）
    { id: "J1", sources: ["D32", "BISURJ"], target: "D26", label: "局部同胚+双射⟹同胚", ref: "Prop 2.31(c)" }
  ]
};

window.registerSubject(window.KG_DATA);   // 必须保留
```

## 边类型与颜色约定

| type | 含义 | 渲染 |
|---|---|---|
| equiv | 双向等价 | 蓝实线 + 两端三角杠箭头（triangle-tee） |
| impl | 单向推论 | 绿实线 + 目标端三角箭头 |
| joint | 联合蕴含 | 红虚线；sources → ∧ 门 → target |
| aux | 证明依赖 | 灰点线（默认隐藏，可开关） |

## 跨学科连接

两种方式：

1. **跨学科边**：在任一学科文件的 `edges` 中引用另一学科节点 id（如拓扑的 D33 → 分析中的 A_Hausdorff 类比）。
2. **合并大网视图**：主图页点「🌐 合并大网」按钮，自动按 manifest 合并所有学科节点与边（需 id 全局唯一，故建议学科前缀）。

## 运行方式

双击 `index.html` 即可（`file://` 协议，无需服务器，全部依赖本地化）。

## 布局交互（间距 / 单球缩放 / 位置记忆）

- **间距滑块**：顶部工具条「间距」滑块（1.00×–3.00×）绕图质心等比放大所有球之间的距离；拖动可撤销（Ctrl+Z），重新布局后回到 1.00×。
- **单球缩放**：右键节点 → 「🔍 放大此球 / 🔎 缩小此球 / ↩ 恢复默认大小」（0.6×–2.5×），放大时自动推开相邻球。
- **位置记忆**：每个学科视图 × 布局的球体相对位置、间距倍率、单球大小自动存入 `localStorage`（键 `kg-layout-v1`）。关闭重开页面原样恢复；**只有右键空白处「🔄 重新布局」才会重排**。
- **撤销**：右键菜单「↶ 撤销上次改变」或 Ctrl+Z（最多 20 步），覆盖拖拽、滑块、单球缩放、重新布局。
- **防重叠**：布局完成后在模型坐标里做空间哈希加速的最小间距后处理，任意两球圆心距 ≥ 半径和 + 8，与缩放级别无关。

## 数字标注（复习模式）

- **三态标注**：顶部「🔢 标注」按钮循环切换：
  - **仅编号**：球内显示数字（按教材页码混排编号，越早出现编号越小）；
  - **编号+短名**：文字以白底标签显示在球下方（不遮球体）；
  - **隐藏**：球上无文字，悬停时仍显示「编号 短名」。
- **初始编号**：由 `data/*.js` 的 `page` 字段升序自动生成（无 page 的排最后），无需手写编号字段。
- **自定义编号**：右键球 →「✏ 自定义编号…」，留空则恢复该球初始编号；顶部「↩ 恢复初始编号」一键清除全部自定义。自定义结果存 `localStorage`（键 `kg-num-v1`），关页不丢。
- **搜索兼容**：搜索仍匹配短名与陈述原文，不受编号显示影响。

## 自定义连接（手动建边）

- **建立**：右键球 →「🔗 连接另一个球」→ 左键点击目标球，两球之间出现**灰色虚线**（无方向）；右键或点空白取消连接模式。重复连接同一对球会被忽略。
- **删除**：右键灰色虚线 →「🗑 删除这条连接」。
- **持久化**：增删**立即自动保存**到 `localStorage`（键 `kg-custom-edges-v1`），关页重开自动恢复；跨学科视图共享（合并大网也能看到）。
- **显隐**：顶部「╌ 我的连接」复选框控制显示/隐藏。
- **撤销**：建边、删边均记入撤销栈（Ctrl+Z / 右键撤销）。
- **侧栏**：节点详情的关系列表中显示「自定义连接」条目（灰色徽标）。
- **管理面板**：顶部「🔗 我的连接」按钮（带连接数徽章）打开面板：
  - 列出全部手动建立的连接（"A ⇄ B"），点击条目定位到图上的对应边；
  - **悬停条目时图上对应虚线由浅灰变为深灰高亮**，移开恢复；
  - 每条可单独删除，或底部「清空全部连接」（有确认）；增删立即自动保存并支持撤销。

## 导入节点（单个 / 批量）

- **入口**：顶部「＋ 导入节点」按钮，弹窗分两个页签。
- **单个导入**：表单填写类型（定理）、短名、标题、陈述（支持 `$...$`/`$$...$$`）、证明、出处，点「生成新球」。
- **批量导入**：粘贴 JSON 数组，规范格式：
  ```json
  [
    {
      "label": "一致收敛定理",            // 短名，必填
      "title": "定理 7.1 一致收敛与连续性", // 详情页标题，可选
      "statement": "设 $f_n \\Rightarrow f$ 一致收敛，则 $f$ 连续。",  // 必填
      "proof": "用 $\\varepsilon/3$ 法。", // 可选
      "ref": "教材 §7.1"                   // 出处，可选
    }
  ]
  ```
- **规范**：`label` 与 `statement` 必填；id 由系统自动生成（`U_<短名>`，冲突自动加后缀）；新球类型固定为 `theorem`（暖橙色）。
- **编号**：手动节点编号排在教材节点之后（如教材共 238 个则从 239 起），**不会打乱教材球编号**；删除后重新导入会接续新编号。
- **显隐**：顶部「我的节点」复选框控制手动导入球显示/隐藏。
- **删除**：右键暖橙球 →「🗑 删除此节点（手动导入）」，连带删除相关自定义连接。
- **持久化**：存 `localStorage`（键 `kg-user-nodes-v1`），自动保存、支持撤销（Ctrl+Z）。双击球打开的详情页同样可查看手动节点。

## 证明笔记（node.html 功能栏）

双击主图节点打开的详情页底部有「📝 我的证明笔记」卡片：

- **文字**：文本框直接粘贴/输入，支持 `$...$` 与 `$$...$$` LaTeX（点「🔍 LaTeX 预览」用 KaTeX 渲染，出错处红色标注）；离开 1.2 秒自动保存，也可点「💾 保存」。
- **图片**：「🖼 粘贴/插入图片」选文件；或复制图片后点「📋 从剪贴板粘贴图片」；在文本框内直接 Ctrl+V 图片也会进入图片区。单张超过 4096px 自动压缩，笔记总量建议 < 4.5MB。
- **导出 / 导入**：导出本页 / 全部为 `.json`（`math-kg-notes` 格式，图片以 base64 内嵌）；导入时选「合并」（只填空位）或「覆盖」。
- **存储**：`js/notes-store.js`，优先 IndexedDB（DB `math-kg-notes`），不可用时降级 `localStorage`（键 `kg-note:<id>`）。笔记按节点 id 存取，与学科无关。
- **主图徽标**：有笔记的节点右上角显示橙色小圆点（刷新主图或切回窗口时更新）。

> 提示：`index.html` 与 `node.html` 都需引入 `js/notes-store.js`（在 data/*.js 之后、页面内联脚本之前）。
